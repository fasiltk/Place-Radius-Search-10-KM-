🌍 Django Place Radius Search (10 KM)

A simple Django project where:

✔ Users can add a place by name only
✔ System automatically fetches latitude & longitude using Geopy
✔ Users can search for nearby places within a 10 km radius

🚀 Features

Add a place using only the place name

Geocode place names into coordinates (Latitude & Longitude)

Store places in database automatically

Find all places within 10 KM radius of a given input place

Built using Django + Geopy

Simple UI with HTML templates
